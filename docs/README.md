# docs/ — 計画書・機能設計書

- `plan/` — プロジェクト計画書などの全体資料
  - 現在の基準： yEgo プロジェクト計画書（2026-11-11）
    「消防設備点検のPDFを『壊さず編集する』ための開発方針・進捗・品質ゲート・次の行動」
    （PDFはローカルの git から追加する）
- `gate-b/` — Gate B の設計書（D1〜D9）を置く場所
- `first-run.md` — 初回実行の指示書（最初の「型」の試作の進め方・止まる条件）
- `routine.md` — 定常運転の指示書（Claude Code の定期実行が三者のやり取りを自動で回すための手順。バトン方式）
- `progress.md` — 進捗のバトン（定常運転の現在地。各サイクルがここから再開し、ここを更新して渡す）

機能設計の成果物はここに入れる。画面・操作の設計は `design/`（もち担当）。
