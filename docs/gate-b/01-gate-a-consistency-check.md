## 4. CSV を受け取ったら行う照合（手順）

読み取りだけで行います。PDF は開きません。

1. `01-corpus-inventory.csv`: 行数 ＝ 988、読み込み失敗 ＝ 1、ページの合計 ＝ 8,571。
2. `02-file-class.csv`: 行数 ＝ 418、区分ごとの数が4章と同じこと。D3・D4 も確かめる。
3. `02-page-layout.csv`: 行数 ＝ 7,988、版が付いた行 ＝ 7,410。罫線なしの区分ごとの数で D1 を、文字数0の行で D6 を確かめる。
4. `02-layout-catalog.csv`: 行数 ＝ 450、点検報告書一式の版 ＝ 256。物件数別の版の数（134／32／90）と、A・B・C 別のページの数を確かめる。
5. 4つの CSV の間で、ファイル ID・ページ番号・版 ID がつながっていること（つながらない行が0）。
6. 結果を `docs/audit/03-gate-a-csv-reconciliation.md` に書く。合わない数は、そのまま記録します。

**判定**: Gate A の数字は、報告書の中ではほぼ合っています（合わないのは2か所・計23件）。ただし CSV と PDF による最終確認はできていません。Gate A は「受領。数字の最終確認は保留」とするのが妥当です。
