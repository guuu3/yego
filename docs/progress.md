# 進捗のバトン（定常運転の状態記録）

定常運転（docs/routine.md）の現在地を記録するファイル。
各サイクルはここから再開し、終わりに必ずここを更新して渡す。

- **現在の作業項目**：最初の型の試作（docs/first-run.md）
- **状態**：未開始
- **完了した単位**：（なし）
- **次にやること**：
  1. 円卓の未記入欄への記入（議題1・議題2）
  2. 対象様式の決定（様式第1を推奨。Gate C で誘導灯の再構成が
     進行中ならそちらを最初の型とする）
  3. 帳票定義への着手
- **停止中の項目と理由**：（なし）

## 更新ルール

- サイクルの最後に、実行した側が更新して push する
- 「次にやること」は、次のサイクルが迷わず再開できる粒度で書く
- 止まった項目は、理由（どこが・どれだけ一致しないか、誰の判断が
  要るか）を添えて「停止中」に残す。黙って消さない
- 議論や決定はここに書かない（円卓 roundtable/ の役割）
