# PC でローカルセッションを開く手順（1から）

様式第1の実測を、原本のある PC で進めるための手順。
分からなくなったら、その画面の文面や写真をもち（このチャット）に
送れば、次の一手を案内する。**エラー文が出たら、直そうとせず
そのまま送ること**（それが一番早い）。

## 0. 準備として分かること

- 必要なものは3つ：①このリポジトリのコピー（PC上）②原本 PDF
  （OneDrive の「点検表」フォルダ）③Claude Code
- 原本 PDF はリポジトリの中には入れない。フォルダの場所を
  Claude Code に教えるだけ

## 1. 黒い画面（PowerShell）を開く

1. キーボードの Windows キーを押す
2. 「powershell」と入力すると「Windows PowerShell」が出るので開く
3. 青い（または黒い）画面に文字が打てる状態になればOK

## 2. リポジトリを PC に持ってくる（初回だけ）

PowerShell に、次の行を1行ずつ打って Enter（貼り付けは右クリック）：

```
cd $HOME\Documents
git clone https://github.com/guuu3/yego.git
cd yego
```

- 「git は認識されていません」のような文が出たら、そこで止めて
  もちにその文面を送る（別の方法を用意する）
- すでに yego フォルダがある場合は、clone の行を飛ばして代わりに：

```
cd $HOME\Documents\yego
git pull
```

## 3. Claude Code を開く

同じ PowerShell で：

```
claude
```

- 初回は確認が出る：「このフォルダを信頼しますか」→ 信頼する／
  MCP サーバーの許可 → 許可、で進める
- Codex の確認が出たら許可する（ログインは済んでいるはず）

## 4. 仕事を頼む

チャット欄に次の一文を貼る。原本の場所は、エクスプローラーで
OneDrive の「点検表」フォルダを開き、上のアドレスバーを
クリックすると出るパスを、そのまま置き換える：

> docs/forms/yoshiki1-first-run.md の §4 の手順で、様式第1の
> 実測をしてください。原本は（ここに点検表フォルダのパス）に
> あります。原本はリポジトリに入れないでください。

## 5. 進んだら

- 作業の結果は Claude Code が main に上げる（または PR 経由）
- もちが1時間おきの定期チェックで結果を拾い、円卓で応答する
- 途中で止まったら、止まった文面をもちに送ればよい
