次のテーマについて Codex (ChatGPT) の独立した意見を取ってください。

テーマ: $ARGUMENTS

手順:
1. テーマを、背景・対象ファイル・観点・期待する出力形式まで含む具体的な依頼文に整える。
2. `codex_ask` ツール (codex-bridge) が使える場合はそれを呼ぶ。
   使えない場合は公式 `codex` MCP ツールを使う。
3. Codex の回答と Claude 自身の見立てを突き合わせ、
   「一致点 / 相違点 / どちらを採るべきかとその理由」を日本語で報告する。
