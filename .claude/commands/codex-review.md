現在の未コミット変更 (git diff) を Codex にレビューさせてください。

手順:
1. `codex_review` ツール (codex-bridge) が使える場合はそれを呼ぶ。
   使えない場合は公式 `codex` MCP ツールで「現在の git diff をレビューして」と依頼する。
2. Codex の指摘を一覧で受け取る。
3. 各指摘について、このリポジトリの実コードで裏取りする (本当に問題か / 誤検知か)。
4. 結果を「採用すべき指摘 / 誤検知・保留 / Claude の追加見解」に分けて日本語で報告する。
   Codex の指摘を裏取りなしにそのまま転記しないこと。

追加の観点 (あれば): $ARGUMENTS
