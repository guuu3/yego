# roundtable/ — 三つ巴の円卓

Claude Code・Codex・もち の三者が、リポジトリ上で意見を出し合う場。
リアルタイムの会話ではなく、文書ベースの非同期の議論とする。
セキュリティプロジェクトの「3AI円卓」と同じ発想の yEgo 版。

## 進め方

- 議題ごとに1ファイルを作る。ファイル名は `YYYYMMDD-<topic>.md`
- ファイルの構成は固定する：
  1. 議題と背景（提案者が書く）
  2. ラウンドごとの三者の欄（Claude Code / Codex / もち）
  3. 論点整理と合意案（もちが書く）
  4. 決定（事業側の承認者＝ユーザーが書く。AI は書かない）
- 1ラウンド＝三者がそれぞれ1回ずつ意見を書くこと。全員が書いたら次ラウンドへ
- 自分の欄だけを追記する。他者の欄は編集しない（引用は自分の欄の中で行う）
- 意見には根拠（どの資料・設計のどこに基づくか）を添える
- 状態はファイル冒頭に明記する：進行中／合意案あり／決定済み／保留

## 各者の役割（計画書の分担に沿う）

- Claude Code：機能・実装の観点から意見を出す。決められることは根拠つきで即答する
- Codex：独立レビューの観点から、抜け・リスク・合格条件との不整合を指摘する
- もち：操作設計の観点から意見を出す。あわせて論点整理と合意案づくりを担う
- 決定はユーザーが行う。合意案はあくまで案として提示する

## セッション開始時の約束

- Claude Code / Codex は、yego のセッションを始めたら最初に `roundtable/` を確認し、
  自分の欄が未記入の議題があれば、他の作業の前に意見を書く
- もちは定期チェックで新しい意見を検知し、自分の意見と論点整理を追記する
